MADAL — Android installable web app (PWA)

Files:
- index.html: MADAL interface
- manifest.webmanifest: install/app identity settings
- sw.js: offline app shell cache
- icons/: Android app icons

Publish all files at the ROOT of the existing GitHub Pages repository (amiir2188-commits/MADAL).
Keep the folders and filenames exactly as they are.
After GitHub Pages deploys, open the site in Chrome on Android, use the ⋮ menu, then choose
'Install app' or 'Add to Home screen'. The browser may show an install button in the page.

This is an installable first version. Podcast audio, user accounts, uploading real videos,
comments shared between users, and a backend/server are not implemented yet.
